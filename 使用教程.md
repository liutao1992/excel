# Java端使用示例

## 定义实体 建立字段映射关系

其中 order表示排序 width 表示列宽度

```java
@Data
public class DataReportDetailBO {

    @ExcelColumn(value="案件编号", order = 1, width = 30)
    private String ajbh;

    @ExcelColumn(value="案件名称", order = 2, width = 36)
    private String ajmc;

    @ExcelColumn(value="主办单位", order = 3)
    private String zbdwmc;

    @ExcelColumn(value="录入时间", order = 6)
    @ExcelDateFormat(pattern = "yyyy-MM-dd HH:mm:ss")
    private LocalDateTime lrsj;

    @DictFormat(dictType = "status")
    @ExcelColumn(value="状态", order = 5)
    private String sfzg;

    @ExcelColumn(value="案件类型", order = 4)
    private String ajlx;
}

```

## 控制层示例

```java

@ApiInfo("数据报表详情-excel文件导出")
@PostMapping(value = "/detail/export")
public ResponseEntity<ByteArrayResource> exportExcel(@RequestBody CaseQueryDTO dto) throws IllegalAccessException {
    try {
        List<DataReportDetailBO> reportDetail = dataReportService.getDataReportDetailList(dto);
        ByteArrayOutputStream out = new ByteArrayOutputStream();
        ExcelExportUtil.setDictService(new SimpleDictService());
        ExcelExportUtil.exportToExcel(reportDetail, "数据报表详情", out);

        ByteArrayResource resource = new ByteArrayResource(out.toByteArray());
        HttpHeaders headers = new HttpHeaders();
        headers.setContentType(MediaType.parseMediaType("application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"));
        headers.setContentDisposition(ContentDisposition.attachment().filename("用户数据.xlsx", StandardCharsets.UTF_8).build());

        return ResponseEntity.ok()
                .headers(headers)
                .body(resource);
    }catch (Exception e) {
        return ResponseEntity.status(HttpStatus.INTERNAL_SERVER_ERROR)
                .body(null);
    }
}
```

## 百分比字段

在字段上添加 `@PercentFormat` 后，字段值按比例存储，并以 Excel 数值单元格的百分比格式显示。比如 `0.1234` 配置 `scale = 2` 后显示为 `12.34%`，单元格仍可参与 Excel 计算。

```java
@ExcelColumn(value = "完成率", order = 7)
@PercentFormat(scale = 2)
private BigDecimal completionRate;
```


# 前端使用示例

```

/**
 * 导出详情数据
 */
exportDetailData(): void {
    this.loading = this.dataReportService.exportDataReportDetail(this.queryParams).subscribe({
      next: (response) => {
        const blob = new Blob([response.body!], {
          type: 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet'
        });
        // 获取文件名
        let filename = `${this.data.detailTitle}`+'.xlsx';
        DownloadUtils.downloadBlob(blob, filename)
      },
      error: () => {
        this.noticeService.fail('导出失败，请稍后再试')
      }
    })
}


exportDataReportDetail(item:any) {
    return this.httpClient.download('data/report/detail/export', item)
}
```
